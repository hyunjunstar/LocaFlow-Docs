# Changelog

## 1.0.0 – initial release

- Dashboard: localization targets and cultures, completion per culture, filters, inline editing, save with `.bak`.
- QA: format arguments, plural / gender / hpp syntax, rich text tags, empty and stale entries.
- Korean particles: detection and one-click conversion to `|hpp(...)`.
- Font Wizard: missing glyph report and fallback sub-font registration from system or custom font files.
- Overflow check for Widget Blueprints per culture, with thumbnails.
- CSV and PO export / import.
- Batch translation via DeepL or OpenAI-compatible endpoints with placeholder protection, cost estimate, per-job cap,
  glossary, retry and rate limiting.
- Runtime Blueprint nodes for an in-game language menu.
- Supported engine versions: 5.5 and 5.8.
