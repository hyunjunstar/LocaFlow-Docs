# LocaFlow Documentation

Localization QA for Unreal Engine 5.5 and 5.8.

LocaFlow helps you find missing glyphs, text overflow, formatting errors, stale translations and Korean particle issues inside Unreal Editor. It also provides CSV/PO exchange and optional machine translation.

## User guides

- [English user guide](UserGuide.md)
- [한국어 사용 설명서](UserGuide_ko.md)
- [Changelog](CHANGELOG.md)

Start with installation and localization target setup in the user guide, then follow the dashboard, QA, font and overflow workflows.

## Compatibility

- Unreal Engine: **5.5 and 5.8**
- Supported and tested editor platform: **Windows 64-bit**
- A localization target gathered with Unreal's Localization Dashboard is required.
- QA works offline. Optional machine translation requires your own provider credentials and may incur separate provider charges.
